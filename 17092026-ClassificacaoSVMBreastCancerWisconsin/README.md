## Atividade Prática sobre classificação com SVM (Support Vector Machine)
> **Objetivo:** Realizar a análise exploratória do conjunto de dados Breast Cancer Wisconsin (Diagnostic) e desenvolver um modelo de classificação utilizando o algoritmo SVM
>
> **Contexto do Dataset**: As características foram computadas a partir de imagens digitalizadas de biópsias por aspiração com agulha fina (FNA) de massas mamárias e descrevem aspectos dos núcleos celulares presentes na imagem. O objetivo é classificar os tumores em Malignos (M) ou Benignos (B)
>
> [Dataset Utilizado](http://kaggle.com/datasets/uciml/breast-cancer-wisconsin-data)
>
> Material e resolução em `svc-breast-cancer-wisconsin-mariasayuri-A6.ipynb`
